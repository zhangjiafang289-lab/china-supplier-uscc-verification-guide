## 1. China 18-Digit USCC (GB 32100-2015) Structure

Every registered Chinese company or market stall holds an 18-character Unified Social Credit Code (`统一社会信用代码`) using a 31-character base set (excluding `I`, `O`, `Z`, `S`, `V`) with a modulo-31 check digit:

| Position | Length | Field | What Buyers Should Check |
|---|---|---|---|
| 1 | 1 | Registration Authority | `9` = State Administration for Market Regulation (SAMR) |
| 2 | 1 | Entity Category | `1` = Enterprise (`91`), `2` = Sole proprietorship / market stall (`92`), `3` = Cooperative (`93`) |
| 3–8 | 6 | Administrative Division | Province, prefecture, and industrial hub (e.g., Yiwu, Shenzhen, Dongguan, Ningbo) |
| 9–17 | 9 | Organization Code | Legacy GB 11714-1997 organization identifier |
| 18 | 1 | Check Digit | Modulo-31 weighted checksum catching mistyped or forged license numbers |
